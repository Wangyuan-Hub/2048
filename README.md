# 2048 小游戏

一个纯 HTML / CSS / JavaScript 实现的 2048 游戏，无需安装任何依赖。

## 运行方式
1. 直接用浏览器打开 `index.html`（最简单，推荐）
2. 或在 VSCode 中安装 Live Server 插件，右键 `index.html` → Open with Live Server
3. 或在目录下启动本地服务器：`python -m http.server 8000`，浏览器访问 http://localhost:8000

## 操作说明
- 方向键 ↑ ↓ ← → 或 WASD 移动
- 触屏设备直接滑动
- 合成 2048 后可选继续挑战更高分
